Source code

WeatherFLOW follows a layered design, separating shared data and evaluation utilities from the model integrations above them. Upstream model repositories are vendored at pinned commits and never modified; each integration is an adapter that wraps the published code behind a common interface for model construction, forward computation, prediction and parameter counting — so every experiment runs the code the original authors released, over identical preprocessed tensors, splits, loss, optimiser, seeds and evaluation suite.

  • WeatherFLOW framework Preprocessing, model adapters, training harness, evaluation suite, experiment configuration and analysis scripts. ZIP

What the archive excludes. Raw and preprocessed station data, trained model checkpoints, the Singularity container image and raw run outputs are omitted — together they exceed 19 GB, and the station data is not ours to redistribute (see Data availability). The archive contains the code required to reproduce the pipeline once the data is obtained from SAWS.

Data availability

The station observations used throughout this project were supplied by the South African Weather Service for research use, under the SAWS data policy. They are not redistributed on this website. The dataset is available on request from SAWS; the list of stations used, with their coordinates and elevations, is given in the appendices of the final papers, so the same network can be requested and reconstructed.

The data contains no personally identifiable information — it comprises physical measurements from automatic weather stations. Station identities and coordinates are reported in the papers because they are a matter of public record and are necessary to interpret the geographic results.

A note on intended use. Forecasts of extreme weather carry asymmetric risk: a missed heatwave or storm costs more than a false alarm. The models evaluated here are not calibrated for operational warning, and these results are reported as a benchmark comparison. They should not be read as evidence of readiness for deployment in a public warning system.

About this site

Static HTML and one hand-written stylesheet. No framework, no build step at view time, no JavaScript, and no external requests — every asset, including the two typefaces, is served from this archive by relative path, so the site renders identically whether it is opened from a web server or straight off disk.

Markup
Hand-written HTML, validated against the W3C Nu HTML Checker
Styling
One stylesheet, CSS custom properties, grid and flexbox; light and dark palettes
Typefaces
Source Serif 4 and Inter, both SIL Open Font License 1.1, subset to Latin and vendored locally
Figures
Extracted from the final-paper PDFs at 240 dpi
